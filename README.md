# Дом с Жуковой — сайт-визитка

Готовый одностраничный сайт Елены Жуковой для размещения на **GitHub Pages**.

## Содержимое

- `index.html` — страницы и тексты;
- `styles.css` — оформление по брендбуку;
- `script.js` — автоматическое обновление года;
- `test.html`, `test.css`, `quiz.js` — отдельная интерактивная анкета и отправка результатов в мессенджеры;
- `assets/elena-zhukova.webp` — оптимизированный оригинальный портрет без изменения лица;
- `assets/og-cover.jpg` — иллюстрация для ссылок в мессенджерах;
- `assets/favicon.svg` — значок сайта;
- `.nojekyll` — настройка для GitHub Pages.

## Как опубликовать на GitHub

1. Войдите на https://github.com и нажмите **New repository**.
2. Назовите его `dom-s-zhukovoy` и выберите **Public**.
3. Создайте репозиторий. Нажмите **Add file → Upload files** и загрузите содержимое распакованного архива (файлы `index.html`, `test.html` и папку `assets`) (сохранив папку `assets`), затем **Commit changes**. Для удобства можно сначала перетащить весь набор файлов и папку `assets`.
4. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, затем **main** и **/(root)**. Нажмите **Save**.
5. Когда публикация завершится, сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/dom-s-zhukovoy/` (замените логин на свой).

> Если GitHub не сохранил пустой файл `.nojekyll` при загрузке — ничего страшного: для этого сайта он необязателен.

## Как изменить информацию

- Тексты, ссылки и структуру: `index.html`.
- Цвета: начало файла `styles.css` (переменные `--green`, `--pink`, `--milk`, `--chocolate`).
- Изображение: замените `assets/elena-zhukova.webp` на файл с тем же именем.

Контакты на сайте: Telegram `@helen_zukova`, MAX (личная ссылка), телефон `+7 952 743-50-97`.

Каналы:
- Telegram: `https://t.me/dom_s_zhukovoy`;
- MAX: `https://max.ru/channel_dom_s_zhukovoy` (ссылка из ранее предоставленных данных: проверьте её при публикации).

## Примечание

Сайт — статический, без платных библиотек, сборщиков и серверной части. Анкета НЕ отправляет данные на сервер и НЕ записывает их в базу: пользователь сам нажимает кнопку в Telegram или MAX и подтверждает отправку.

- Telegram: `https://t.me/helen_zukova?text=...` — сразу открывает личный чат с подготовленным текстом, если клиент Telegram это поддерживает.
- MAX: официальный `https://max.ru/:share?text=...` открывает выбор чата и подготавливает текст. Посетителю нужно выбрать личный чат Елены и подтвердить отправку. На некоторых настольных клиентах поддержка ограничена. На всякий случай добавлены кнопки копирования результата и открытия личного MAX-чата.
- На странице нет сторонней аналитики и автоматической отправки личной информации. Для автоматического сбора лидов без подтверждения посетителя потребуется сервер или бот.
- Для корректной предпросмотровой карточки после публикации можно указать в `og:image` полный URL изображения.


## Расширенный тест и галерея планировок

Анкета устроена как **ветвящийся опрос**: посетитель видит только вопросы по выбранному направлению. Для строительства дома она включает 20 шагов, для готового загородного дома — 17, остальные сценарии короче.

В ветке домов покупатель выбирает этажность, площадь, число спален, наличие отдельного кабинета, гараж/навес/парковку, дополнительные помещения, а затем одну из **11 схематичных планировок от 76 до 242 м²**. Галерея сперва показывает 4 наиболее близких варианта по выбранным параметрам, но кнопка позволяет посмотреть все 11. Покупатель может выбрать одну идею, попросить индивидуальную планировку или не выбирать пока.

**Предупреждение:** схемы планировок иллюстративные, не в масштабе, без технических размеров и инженерной документации, не являются предложениями подрядчиков. Площадь дана ориентировочно; планы с гаражом условно включают гараж в общую концепцию. Перед строительством потребуется технический проект и подтверждение у выбранного подрядчика.

Чтобы изменить вопросы или набор планировок, откройте `quiz.js`: таблицы `interestChoices`, `floorsChoices` и другие задают варианты ответов, массив `plans` — список идей, объект `layouts` — изображение комнат на схемах. При выборе варианта его идентификатор, название и основные характеристики попадут в заявку.

Опрос не обещает цены/сроки строительства, ипотечное одобрение и автоматическую отправку ответов. Посетитель должен вручную подтвердить отправку заявки в выбранном мессенджере; при проблемах с передачей текста предусмотрено копирование.

## Галерея архитектурных стилей

Новый шаг в ветке домов: пять визуальных образов — современный минимализм, барнхаус, скандинавский дом, классический коттедж и двухэтажный дом с гаражом. Пять фотографий `assets/style-*.webp` — иллюстрации архитектурных направлений; это не реальные предложения о продаже. Выбор сохраняется в итоговом сообщении заявки. Чтобы заменить изображения, сохраните имена файлов и формат WebP.

## Проверка перед запуском

- Проверьте, что ссылки на **ваши каналы** Telegram и MAX действительно работают.
- Пройдите тест на телефоне и убедитесь, что сообщение открывается корректно и вы можете его получить.
- Согласуйте, как информировать пользователей об обработке персональных данных, если будете собирать номера телефонов и заявки.
